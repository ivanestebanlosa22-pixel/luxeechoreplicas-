QC Checklist for Yeezy 350 V2

  • Check side stripe: should be semi-transparent on light colorways, solid on dark
  • Primeknit pattern should be consistent with no loose threads
  • Boost sole should be slightly textured (not too smooth)
  • Inner tag should match the colorway's correct format
  • Heel pull-tab should be tight, not floppy
